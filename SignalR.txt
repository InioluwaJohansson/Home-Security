# 📡 SignalR Real-Time Events Reference

This document contains all recommended SignalR realtime events, payload structures, and frontend listeners for the Home Security System.

---

# 🏠 Hub Endpoint

```typescript
const connection = new signalR.HubConnectionBuilder()
  .withUrl("https://localhost:5001/homeSecurityHub", {
    accessTokenFactory: () => token
  })
  .withAutomaticReconnect()
  .build();

await connection.start();
```

---

# 🔔 General Event Structure

All realtime events should follow this format:

```json
{
  "eventType": "string",
  "message": "string",
  "timestamp": "2026-05-18T10:30:00Z",
  "data": {}
}
```

# 🌐 FRONTEND LISTENER EXAMPLES

## React Example

```typescript
connection.on("LightUpdated", (payload) => {
    console.log(payload);

    setLights((prev) =>
        prev.map((x) =>
            x.id === payload.data.id
                ? {
                    ...x,
                    isActive: payload.data.isActive,
                    brightnessLevel: payload.data.brightnessLevel
                  }
                : x
        )
    );
});
```

---

# 🔒 AUTHENTICATED USERS ONLY

Your backend service should use:

```csharp
await _hub.Clients.Group("AuthenticatedUsers")
    .SendAsync(eventName, payload);
```

And in your hub:

```csharp
public override async Task OnConnectedAsync()
{
    if (Context.User.Identity?.IsAuthenticated == true)
    {
        await Groups.AddToGroupAsync(
            Context.ConnectionId,
            "AuthenticatedUsers"
        );
    }

    await base.OnConnectedAsync();
}
```
